WanderLust – Vacation Rental Platform

WanderLust is a full-stack MERN-based vacation rental platform that allows users to explore, list, and manage vacation properties online. Users can browse available stays, view detailed property information, and find suitable accommodations for their trips.

The project includes features such as user authentication, property listings, image uploads, reviews and ratings, location-based property information, and CRUD operations for managing listings. It is designed with a responsive and user-friendly interface to provide a smooth experience across devices.

Tech Stack: MongoDB, Express.js, React.js, Node.js, JavaScript, HTML, CSS, Bootstrap/Tailwind CSS, REST APIs.
